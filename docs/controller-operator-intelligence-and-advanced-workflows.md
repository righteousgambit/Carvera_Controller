# Operator intelligence and advanced-machine workflows

These 25 requirements retain the latest recommendation scope under the active
implementation objective. They supplement existing workflow ledgers. Every complete
workflow remains OPEN; a source model, declaration or narrow UI check does not close
execution or physical acceptance. Local source/package/native inspection authority
does not authorize machining, automatic actuation or machine configuration writes.

| # | Requirement | Required acceptance evidence |
|---|---|---|
