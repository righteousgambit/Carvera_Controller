# Process explanation and advanced machine workflows

These 25 requirements preserve the latest requested implementation scope. They
supplement existing ledgers. Complete workflows remain OPEN until source,
native interaction, supported backend execution and relevant physical acceptance
have independent evidence. Local implementation does not authorize machining,
configuration writes, automatic adaptation or new external publication.

| # | Requirement | Required acceptance evidence |
|---|---|---|
| 1 | Selection-following workbench | Bore, cutter, fixture, operation and alarm selection routes relevant controls; pinned comparison retains context. |
| 2 | Semantic viewport zoom | Machine-scale relationships and feature-scale dimensions/contact/rest-stock detail adapt to scale without hiding required state. |
| 3 | Interactive coordinate explanation | Selected point exposes MCS/fixture/vise/stock/WCS/tip chain and measured versus estimated transforms. |
| 4 | Precise direct manipulation | Stock/vise/tool editing, hole snapping, numeric constraints and local undo round trip. |
| 5 | Edit consequence preview | Tool/stock/jaw/offset changes identify affected operations, clearance and invalidated checks. |
| 6 | Geometric revision comparison | Captured revisions overlay added/removed cuts and material/clearance consequences, including unclassified changes. |
| 7 | Consistent desktop interactions | Keyboard focus, resizing, tables, selection, paste and validation work across all native workflows. |
| 8 | Assembly-aware asset browser | Preview/search cutter, holder, jaws, plate, stock and setups with compatibility before insertion. |
| 9 | Plan versus observed state | Tooling, offsets and pose comparison exposes actionable mismatches and stale observations. |
| 10 | Ordered intervention queue | Tool banks, inspection, optional stops, accessories and alarms retain timing, interruption and resolution. |
| 11 | Operation process envelopes | Rough/finish/drill/thread policies expose bounded permitted behavior and qualified execution. |
| 12 | Adaptive commissioning bench | Per-assembly/material noise, unloaded behavior, latency, response and repeatability establish policy evidence. |
| 13 | Machine-local adaptive service | Actual adapter sampling/actuation bounds, disconnection behavior and desktop supervision are measured and qualified. |
| 14 | Engagement forecast | Remaining-stock entry/full engagement/exit predictions compare against observations with uncertainty. |
| 15 | Performance profiler | Predicted/observed operation time separates acceleration, short moves, ramping, tool changes, probing and intervention. |
| 16 | Surface-quality prediction | Geometric scallop/cusp/feed-spacing estimates link operations and remain distinct from measured finish. |
| 17 | Feature accessibility map | Assemblies/orientations expose reach, clearance and travel blockers using declared and qualified geometry. |
| 18 | Five-axis configuration comparison | Alternatives show limits, rotary travel, clearance and singularity proximity before path selection. |
| 19 | Rotary transition planning | Retract/index/unwind/clamp/reentry are explicit, simulated and backend-qualified. |
| 20 | Kinematic model reconciliation | Observed joints/tip compare declared pivots, directions, length and transforms with capable backend data. |
| 21 | Magazine scheduling | Preselection, oversized/reserved pockets, sister availability and fixed/random semantics reconcile actual inventory. |
| 22 | Objective-led probing | Datum/feature objectives generate accessible contact directions/repeats and retain raw results. |
| 23 | Measure/correct/finish | Nominal, measurement, bounded radial/diametral correction, predicted effect and reinspection retain part identity. |
| 24 | Accessory sequence editor | Clamps/coolant/air/extraction/doors/pallets/spindle distinguish immediate and motion-synchronized actions plus observed feedback. |
| 25 | Executable backend test environment | Actual UI and adapter contracts exercise delays, stale offsets, incomplete changes, alarms and disconnects. |
