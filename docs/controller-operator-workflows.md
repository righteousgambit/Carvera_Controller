replace or close the existing ledgers. Source foundations, installed interaction,
real backend execution and physical qualification are separate evidence gates.

## Inline bank review checkpoint

The bank review now groups mapping, inherited modes/checks, transformed source
and complete source into separate views. Source pagination and exact-line
navigation expose later lines without a first-300-line omission. This improves
preparation ergonomics, not stop/reload/offset/re-entry execution.
