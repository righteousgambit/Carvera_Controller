# Indexed setup review

Machine > Five-axis reachability & branches > Indexed 3+2 setup holds every
rotary angle fixed and maps one to eight ordered workpiece XYZ points to exactly
three independent linear axes. It uses the declared tool/work chains, base
transforms, pivots and spindle-origin-to-tip length. Fixed angles accept the
angle editor's unit expressions and must respect the declared travel.

Use selected branch orientation explicitly copies the rotary angles of a
locally converged branch. It does not move or index the machine. Enter work
points in canonical millimetres, one XYZ triple per line, then Map work points.
Choose a point to inspect its joint positions and remaining travel. Reviewing
points does not replace an existing joint route. Copy to joint route is a
separate action; it opens transition review and invalidates obsolete results.
Review the copied route before interpreting its sampled geometry.

The pure engine solves the fixed-rotation affine map with a three-column linear
basis. It rejects dependent or ill-conditioned linear directions, nonfinite or
out-of-range inputs, missing/extra rotary axes and any point outside declared
travel. One invalid point rejects the complete result. Cancellation and changed
inputs discard work rather than publishing a partial/stale mapping. Full rotary
angles are retained; no angle-equivalence shortcut silently changes the setup.

Linear interpolation between mapped joint states follows the work-space chords
with that orientation fixed. This does not supply an indexing approach, safe
clearance, fixture registration, physical offsets, feed, TCP compensation,
controller coordinate conventions or a backend/postprocessor. Those gates remain
open. No machine command or executable program is generated by this workflow.

Source verification: topology, rotated-base/pivot/tool-length, work-chain linear
axes, non-orthogonal basis, dependent basis, travel and cancellation cases are
covered. Workbench checks cover branch handoff, explicit joint-route transfer,
point selection, unit-aware controls, stale-result rejection, no command dispatch
and a visually reviewed 360 dp layout. Installed/native acceptance is separate.
